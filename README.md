# odin-recipes

This was a basic overview of creating content in HTML. I created a site with three different recipes, using only HTML. The home page (index.html) includes both absolute and relative links to other content. Each recipe page has multiple heading types from h1 to h3 depending on importance, as well as unordered and ordered lists.

I'm surprised how quickly I was able to pick this back up after starting The Odin Project some time last year and eventually losing the drive. I have retained more information than I expected to, which allowed me to start and finish this project in about an hour or so. I am hoping this confidence will continue into the parts that I will inevitably struggle with so that I can complete the course in full this time!
